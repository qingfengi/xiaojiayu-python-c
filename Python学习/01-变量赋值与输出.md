## 2. 变量：给数据一个名字

先看下面这四行：

```python
minutes = 10
extra_minutes = 5
total_minutes = minutes + extra_minutes
print(total_minutes)
```

输出：

```text
15
```

逐步理解：

1. `10` 和 `5` 是整数，也就是没有小数部分的数；它们是程序要处理的数据。
2. `minutes` 是变量名。变量让我们通过一个名字找到当前对应的值。`minutes = 10` 让这个名字当前对应整数 `10`。
3. `extra_minutes = 5` 让另一个名字对应整数 `5`。这里的两个英文名字分别表示“分钟数”和“额外分钟数”，你也可以选别的名字。
4. `minutes + extra_minutes` 先取这两个名字当前的值，再相加，得到 `15`。
5. `total_minutes` 表示“总分钟数”。它在这次赋值后对应 `15`。

`minutes + extra_minutes` 这样的写法叫**表达式**：Python 对它进行计算，就能得到一个值。单独的 `10` 或 `minutes` 也可以是表达式。

为什么要用变量？如果多处需要同一份分钟数，我们可以通过有含义的名字使用它，也能在需要时更新这个名字对应的值。

变量名的本课写法：使用英文字母、数字和下划线 `_`，不能以数字开头；大小写不同就是不同名字，例如 `minutes` 和 `Minutes`。不能使用 `if` 这样已经被 Python 留作特定用途的词，这些词叫“关键字”。这是一种便于学习的命名方式，Python 也允许一些其他字符，包括中文。避免给变量起名为 `print`，否则会遮住我们接下来要用的显示功能；`print` 不是关键字，但本课需要保留它原来的作用。

## 3. 赋值：先算右边，再更新左边

`=` 在这里叫**赋值符号**。赋值的意思是：先得到右边的值，再让左边的变量名对应这个值。

```python
minutes = 10
minutes = minutes + 5
print(minutes)
```

输出：

```text
15
```

第二行的过程是：

1. 先看右边，此时 `minutes` 对应 `10`。
2. 计算 `10 + 5`，得到 `15`。
3. 让左边的 `minutes` 改为对应 `15`。

所以 `minutes = minutes + 5` 能成立，它是一条更新指令。数学中的等式要求左右相等，而这条 Python 指令要求按顺序完成一次赋值。以后判断两个值是否相等，会使用另一个符号 `==`。

## 4. 顺序执行：计算发生在那一行执行时

本课这些代码按从上到下的顺序执行。这一点只针对这里的普通顺序代码；以后会学到让程序选择或重复执行的规则。

```python
minutes = 10
total_minutes = minutes + 5
minutes = 20
print(minutes)
print(total_minutes)
```

输出：

```text
20
15
```

| 执行完哪一行 | minutes 当前对应 | total_minutes 当前对应 |
| --- | --- | --- |
| `minutes = 10` | 10 | 还没有建立这个名字 |
| `total_minutes = minutes + 5` | 10 | 15 |
| `minutes = 20` | 20 | 15 |

为什么 `total_minutes` 还是 `15`？因为第二行执行时只计算了一次 `10 + 5`，并把结果与这个名字关联。后来更新 `minutes`，没有再次执行第二行。赋值不会建立一个以后自动重新计算的公式。

如果想根据新的 `minutes` 重新得到总数，就要再执行一次 `total_minutes = minutes + 5`。

同理，`a = 10` 后执行 `b = a`，是让 `b` 也对应此时的整数 `10`。随后执行 `a = 20`，只是更新 `a` 对应的值，`b` 仍对应 `10`。这里不需要讨论计算机内存，先把每个名字当前对应什么说清楚。

## 5. print：把结果显示出来

**函数**可以先理解为一个有名字、能让它执行的操作。`print` 是 Python 自带的函数，用于显示交给它的内容，不需要安装。

`print(total_minutes)` 表示现在执行这个显示操作，这叫**调用函数**。括号里的 `total_minutes` 是交给它的内容，叫**参数**；这里 Python 会先取出这个名字对应的值，再交给 `print`。

**输出**就是程序向外显示或给出的结果；本课的输出指终端里显示的文字。单独赋值通常不会让 `.py` 文件显示结果，所以我们明确写 `print(...)`。

某些允许逐行输入 Python 的交互窗口会自动显示表达式结果，那是交互窗口提供的便利，不代表 `.py` 文件会自动显示每个变量。

## 6. 引号：区分文字与变量名

**字符串**就是一段文本，可以包含汉字、字母、数字和标点。最简单的写法是把文本放进一对英文单引号或双引号中，比如 `"minutes"`、`"10"`。两端的引号要配对。

```python
minutes = 10
print(minutes)
print("minutes")
print(10 + 5)
print("10" + "5")
```

输出：

```text
10
minutes
15
105
```

- `print(minutes)`：没有引号，查找变量名对应的值，所以显示 `10`。
- `print("minutes")`：有引号，是直接显示这段文字，所以显示 `minutes`。
- `10 + 5`：两个整数相加，得到 `15`。
- `"10" + "5"`：两个字符串相接，得到文本 `105`。这种首尾相接叫**拼接**。

**数据类型**说明一个值属于哪一类，也会影响操作规则。本课的两类是整数和字符串。整数的类型名称是 `int`，字符串的类型名称是 `str`，暂时只需要认得这两个名字。

引号是代码里标明文本边界的符号。`print("10")` 会显示 `10`，不会把外层引号也显示出来。因此，仅凭看到的输出 `10`，不能断定原来的值一定是整数。

## 7. 遇到错误，先检查这三件事

错误提示是 Python 告诉你哪里无法继续执行。先看提示的最后一行，再回到它指出的代码行。

| 检查点 | 故意写错的例子 | 正确理解 |
| --- | --- | --- |
| 英文标点是否配对 | `print（10）` | 代码括号用英文 `()`。字符串内部可以正常写中文标点 |
| 名字是否已经赋值、大小写是否一致 | 没有先赋值就写 `print(Minutes)` | Python 不知道这个名字当前对应什么 |
| 相加的数据类型是否匹配 | `"10" + 5` | 文本和整数不能这样直接相加；先明确想计算数字还是拼接文本 |

对应的常见提示名称分别是 `SyntaxError`（写法不符合语法规则）、`NameError`（找不到所用名字）、`TypeError`（当前操作不适用于这些数据类型）。这些是帮助定位问题的类别，不需要死记英文解释。

这里的错误例子只是用于说明，不应抄入正常示例文件一起运行。

## 补充：函数写法中的每个符号

后续讲函数时，不跳过这些基础细节。

```python
def add_numbers(a, b):
    result = a + b
    return result
```

- `def` 是 define（定义）的缩写，是 Python 的关键字，告诉 Python“接下来要定义一个函数”。关键字是语言已经占用、不能拿来当普通变量名的词。
- `add_numbers` 是函数名。它由 `add` 和 `numbers` 组成，中间的 `_` 叫下划线。Python 社区常用“小写单词加下划线”命名函数，这种格式叫 snake_case（蛇形命名）；下划线只是名字的一部分，不会自动产生特殊运算。
- `(` 和 `)` 是圆括号。定义函数时，括号里列出参数；调用函数时，括号里写实际传入的值。
- `a, b` 是两个参数名。逗号 `,` 用来分隔多个项目。它们是函数内部临时使用的名字，调用时会分别接收传入的值。
- `:` 是冒号，表示函数头结束，下一行开始是函数体。函数体就是函数真正执行的代码。
- 下一行前面的 4 个空格叫缩进。缩进把代码划入函数体；同一函数体内通常保持相同缩进。Python 用缩进表达代码的层级。
- `result` 是变量名，意思是“结果”。`result = a + b` 先计算右侧，再把结果赋给 `result`。
- `return` 是返回关键字。`return result` 的意思是：停止执行当前函数，并把变量 `result` 当前对应的值交给调用它的地方。`return` 后面的 `result` 是变量，不是固定文字；如果写成 `return "result"`，交出去的就是字符串 `result`。

调用：

```python
answer = add_numbers(12, 5)
```

这里 `add_numbers` 是要调用的函数名，`12` 和 `5` 是实参，也就是这次调用实际传入的值。调用时，`a` 临时对应 `12`，`b` 临时对应 `5`；函数返回 `17` 后，`answer` 接收这个返回值。定义函数只是登记一套步骤，调用函数才会执行这些步骤。
