## 1. 类型和值

数据类型就是数据的类别。例如整数 6 属于 int 类型，文字 "Python" 属于 str 类型。布尔类型是用来表示真或假的数据类别，在 Python 中叫 bool；这个名称来自 Boolean（布尔）。

布尔类型只有两个值：True（真）和 False（假）。这里的“真、假”通常表示一个条件成立或不成立，不是在评价一段内容的好坏，也不表示程序有没有报错。

类型是类别，值是具体内容：bool 是类型名，True 和 False 是这种类型的两个值。

True、False 在 Python 中是保留的关键字写法。关键字指语言规定有特定用途的词。它们首字母大写，不加引号，不需要括号调用。"False" 加了引号就是字符串，而 False 没有引号才是布尔值。

## 2. 判断可以得到布尔值

```python
print(3 < 5)
print(3 > 5)
```

输出依次为 True、False。`<` 是小于，`>` 是大于；它们属于比较运算符，即用来比较两个值的符号。Python 先计算括号里的比较，得到布尔值，再由 print 把它显示出来。

## 3. 布尔值的用途

```python
score = 75
passed = score >= 60
print(passed)

if passed:
    print("通过")
else:
    print("未通过")
```

score 是成绩，passed 在这里表示“是否通过”。第一行赋值 75；第二行先计算右边的 75 >= 60，得到 True，再把 True 赋给 passed。`>=` 表示大于或等于；`=` 仍然只表示赋值。

输出为 True 和“通过”。if 检查 passed 的真假，当前为真，执行它下面缩进的显示语句；否则执行 else 的部分。if 与 else 对齐，各自内部用四个空格缩进。

## 4. and、or、not

它们都是 Python 的逻辑运算符，也是关键字，不是普通函数；代码中用小写。逻辑运算符是把判断组合起来或反转判断的词。以下只讨论输入已经是 True、False 的情况。

| 写法 | 读法 | 规则 |
| --- | --- | --- |
| 左边 and 右边 | 左边并且右边 | 两边都为真，结果才为真 |
| 左边 or 右边 | 左边或者右边 | 至少一边为真，结果就为真；两边都真也为真 |
| not 后面的值 | 对后面的值取反 | 真变假，假变真 |

| 左边 | 右边 | and 结果 | or 结果 |
| --- | --- | --- | --- |
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

```python
print(True and False)
print(True or False)
print(not True)
print(not False)
```

输出依次为 False、True、False、True。因此 not 不是固定输出 False，也不是循环。for 是另一种用于重复执行代码的关键字，后面的课程再讲。

它们的基本写法是 `条件1 and 条件2`、`条件1 or 条件2`、`not 条件`。括号可以用来分组，比如 `not (3 < 5)`；这里的括号不是函数调用。

not 得到相反的布尔结果，本身不会修改原变量。例如 passed 是 True 时，not passed 得到 False，但 passed 本身仍然是 True，除非另写赋值语句更新它。
