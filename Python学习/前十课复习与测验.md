## 模块与浮点信息补讲

模块是可以用 import 导入的一份代码组织单位，其中可以提供函数、类型和信息。模块不一定都是普通 .py 文件，有的由解释器直接提供。import 是关键字，不是函数；导入 Python 自带模块无需下载。

```python
import sys
print(sys.float_info.dig)
print(sys.float_info.max)
```

sys 的名字来自 system，意为系统；此模块主要提供 Python 解释器的信息和与解释器交互的功能。例如 sys.version 提供版本信息。解释器是实际执行 Python 代码的软件。

float_info 是 sys 提供的浮点信息对象。对象在这里先理解为一份可以读取其中各项信息的数据；这些有名字的信息项称为属性。float 是浮点数，info 是 information（信息）的缩写。下划线是名字的一部分，写成 float-info 则变成减法写法。

点号用于访问左边对象的属性：sys.float_info 取得浮点信息，再用 .dig 或 .max 取得某一项。这里不是调用函数，因此 dig、max 后不加括号；外面的 print(...) 才是函数调用。

dig 来自 digits（数字位数），本机为 15。这不是固定保留小数点后 15 位，而是浮点表示的一项十进制有效数字保证：在可表示范围内，至多 15 位十进制有效数字转成 float 后再按这些位数转回，能够保持这些数字。它不保证任意多步计算都精确到 15 位。二进制双精度有 53 位二进制有效精度；有时为区分相邻浮点值，需要显示到 17 位十进制有效数字。

max 来自 maximum（最大值），本机为 1.7976931348623157e+308，表示约 1.7977 乘以 10 的 308 次方。这是最大的有限正浮点值，描述数值范围，不是精度。e+308 是科学计数法的写法，后续专门补讲。不要把 sys.float_info.max 与另一个同名的内置函数 max(...) 混淆。

## decimal 和 Decimal

decimal 是英文“十进制的”；Python 的 decimal 模块提供十进制数值计算工具。Decimal 是该模块中的一种数值类型，大小写有区别。

```python
import decimal
a = decimal.Decimal("0.1")
b = decimal.Decimal("0.2")
print(a + b)
```

输出 0.3。decimal.Decimal 是访问模块中的 Decimal 类型；后面的括号传入字符串，构造一个这种类型的数值。构造在这里指创建一个新的十进制数值，并非调用普通的自定义函数。

这也可以写成：

```python
from decimal import Decimal
a = Decimal("0.1")
b = Decimal("0.2")
print(a + b)
```

from 表示“从……中”，import 表示“导入”；此句把 Decimal 这个名字直接引入当前代码，因此后面可以不写 decimal.。这里不是两个不同的工具，只是两种导入写法。

使用字符串是为了让 Decimal 直接读入十进制文本。Decimal(0.1) 也合法，但它接收的是已经被 float 近似表示的数值，会保留这个近似值，而不是自动恢复我们想要的精确 0.1。

Decimal 不是无限精确的万能工具：运算也受设定的精度影响，例如 1/3 不能用有限位十进制小数精确写完。当前无需安装它或背高级设置，掌握用途及上述写法即可。

## 已发现的教学问题与修正

- 用户明确 abs(-4) 是 4，此前含糊回答可能是语音转写错误，不作为“不会绝对值”的证据。
- 3、9、8 的猜数序列是由第三次猜中的 break 结束，不是机会归零；此前附和“因为条件不满足”不准确。正常用尽机会与 break 提前退出须分别检测。
- round 不是一概使用日常四舍五入：恰好居中时选偶数，如 round(2.5) 为 2、round(3.5) 为 4。该内容非本轮考点，不能用尚未教过的边界扣分。
- // 是取不大于商的最大整数，不是严格“小于商”；整数可整除时商不应再减一。浮点操作数如 7.0 // 2 的结果是 3.0，数值已向下取整但类型仍为 float。
- 原课转录“整数无限精度”需限定：整数没有固定的位数上限，但受可用内存等资源限制。
- 第 008 讲的随机数旁白不可照搬：真正随机来源不只量子纠缠，也不必等量子计算机；随机结果可能重复，两人结果也可能相同。random 默认优先使用操作系统提供的随机来源初始化，不能简单说总是系统时间。
- 第 009 讲的单位转录应核对为 50 微米 = 0.00005 米 = 5e-5 米；复数虚部属性是 imag，不是 image。
